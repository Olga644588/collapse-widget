# Collapse Widget

Виджет сворачиваемых контейнеров на чистом JavaScript (без jQuery). Реализован в виде отдельного класса, собирается через Webpack и деплоится на GitHub Pages с помощью GitHub Actions.

## Технологии

- JavaScript (ES6+) — класс `Collapse` с методами `open()`, `close()`, `toggle()`
- Webpack 5 — сборка JS-модулей, CSS и ассетов
- Babel — транспиляция современного JS
- GitHub Actions — CI/CD и автоматический деплой
